## 1. 構成
| ブロック | 図 | 内容 |
|---|---|---|
| 電源入力・メインリレー・自己保持 | 図1 | +B → F1 → K1接点 → VSW。コイルは ACC（D1）か、VSWからQ2（自己保持） |
| 保持タイマー | 図2 | HN（C1の電圧）が比較器U1Aのしきい値を超えている間、Q2をON。HNは ACC（R2）とマイコンのチャージポンプ（Q4・C2・D6/D7）で充電、R1で放電、Q5で急速放電 |
| ハブ用5V | 図3 | LM2576HVS-ADJ（5.0V）＋低電圧停止（Q6） |
| USBハブ・ポート電源 | 表（4章） | CH334R×2で7ポート、TPS2553で各ポートの電源ON/OFFと過電流検出、TCA9555で制御 |
| 電圧監視 | 図1注記 | ACC・VSW を 68k/6.8k で XIAO の D0・D1 へ |

### 動作のしかた（保持タイマー）
- **ACC ON**：D1でコイルに直接電流が流れ、約10msでリレーON。同時にACCがR2経由でHNを充電する
- **マイコン起動後**：XIAO D3 から約1kHzの矩形波 → Q4 で VCMP 振幅にして C2・D6/D7 で整流（チャージポンプ）→ HN が約9Vまで上がり、U1A→U1B→Q3→Q2 でコイルを保持
- **ACC OFF**：マイコンがポンプを続ける間は保持。PCの終了を確認したら **D2（DISCH）をH → 約30msでOFF**
- **マイコンが止まった・固まった**（ピンがH・Lのどちらに固まっても）：ポンプが止まり、R1でHNが放電 → **約13〜40秒で必ずOFF**（暗電流ゼロを保証）
- **クランキング（ACCが切れる・+Bが6V）**：HNの電荷で保持し続ける

## 5. SPICE評価の結果（26ケース・80項目：FAIL 0、WARN 7）
| 試験 | 結果 |
|---|---|
| 通常のシーケンス | ACC ONから0.11秒でON。PC終了中（30秒）も保持。DISCHから54msでOFF |
| マイコン故障（ポンプなし） | ACC OFFから13秒でOFF（ACCの時間が長いと最長約28秒） |
| マイコンが固まる | 固まってから37秒でOFF |
| 始動（ACC 3秒断・+B 4.5V→6V、マイコンもリセット） | リレーは保持（VSW 4.5V以上＝+Bと同じ） |
| ACC ON直後（0.5秒）の始動 | 一度切れて、始動後にACCが戻ると再びON（マイコン起動前なので実害なし） |
| 保持コンデンサが4.7µFに減った | 12秒保持（問題なし） |
| 9〜35V の定常 | 9Vでもリレーが入る。Q2のVgsは最大−11.9V（定格±20V）。TL431の電流1.3mA以上 |
| ロードダンプ（35V・0.2秒） | TVSは導通しない（電流ほぼ0）。5Vは4.98Vのまま |
| ISOパルス2a（+50V/2Ω） | VSW最大15V（PCモジュールあり）、25V（なし） |
| ISOパルス1（−75V/10Ω） | VSW −0.7V、U3の入力は+4.4V（D11で保護） |
| 逆接 −14V | リレーは閉じない。ACCから0.2mA（分圧抵抗）だけ |
| 暗電流（駐車中） | +B・ACCとも回路上の経路なし（モデルの接点開放抵抗1GΩ分の12nAだけ） |
| 5V（TIのスイッチングモデル） | 9〜35V・2Aで4.99〜5.03V、リップル17〜48mV |
| 低電圧停止 | 6.27Vで起動、4.08Vで停止 |

### 要注意（WARN）
| # | 内容 | 値 | 対応案 |
|---|---|---|---|
| W1 | リレーが閉じた瞬間の突入電流 | **ピーク126A**、I²t 2.1A²s | PC用DC-DCモジュールの入力コンデンサ（470µFと仮定）が主因。実物の容量を確認したい。下げるならPC側の分岐にソフトスタート（Pch MOSFET）を追加（**質問Q1**） |
| W2 | 24Vジャンプスタート中のリレーコイル | 1.56W（定格0.4Wの約4倍、最大電圧180%を超える） | 60秒なら焼けない見込みだが保証外（**質問Q2**） |
| W3 | 35Vロードダンプ中のコイル・R5 | 3.3W・0.37W（0.2〜0.4秒） | 短時間なので許容 |
| W4 | 始動中（+B 6V）の5V | 0V（ハブ・ノードはリセット） | 降圧なので6Vからは5Vを作れない。始動後に自動で復帰（設計書どおり） |
| W5 | 5V・3A・入力24V | 4.52V、リップル0.38V（TIモデル） | **ハブの5Vは合計2A以下で使う**（ノード3台＋ハブで約1.5A） |

## 6. SPICEで見つけて直したこと
| # | 問題 | 直し方 |
|---|---|---|
| 1 | Q2（Pch）のボディダイオードを通って、**ACCからVSWへPCの電流が流れ込む**（リレーが閉じず、D1とACCのヒューズに数A） | D8（SS14）をQ2のドレインに直列に追加 |
| 2 | ACC 9Vでリレーが入らない（D1の降下0.85Vでコイル8.1V＜動作電圧8.4V） | D1・D8をショットキー（SS14）に |
| 3 | TL431の電流が9Vで0.73mA（最小電流の最大値1mA未満） | R6 4.7k→2.2k |
| 4 | ADCの入力が24V以上で3.3Vを超える | 分圧を47k→68k（比11.0） |
| 5 | LM2576の入力に、ISOパルス1・逆接で逆電圧がかかる | D11（SS56）を直列に |
| 6 | 低電圧で LM2576 がON/OFFを繰り返すおそれ | 低電圧停止（Q6）にヒステリシス（R43） |

## 8. 質問・確認したいこと
- **Q1** 突入電流126A：PC用DC-DCモジュールの入力コンデンサの容量が分かれば教えてほしい。下げる回路（ソフトスタート、部品代 数十円）を入れるか
- **Q2** 24Vジャンプスタート：リレーのコイルが60秒間 定格の約4倍になる。許容するか（注意書きで対応）、コイルの電流を制限する回路を足すか
- **Q3** ACCを入れてすぐ（約1秒以内）エンジンをかけると、PHUが一度切れて始動後に入り直す。PCはまだ起動していないので実害はないが、この動作でよいか
- **Q4** 成果物の置き場所：今回は「Claude outputs/phu-v0.1」に置いた。リポジトリの中に hardware フォルダを作ってよいか（以前 hardware を削除したコミットがあるため確認）
