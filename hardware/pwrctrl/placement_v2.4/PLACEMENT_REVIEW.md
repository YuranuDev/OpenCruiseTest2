v2.3（`placement_v2.3/PLACEMENT_REVIEW.md`）に、ユーザーの判断3点を反映した版。配線はまだしていない。

| 判断 | 対応 |
|---|---|
| 1. CANトランシーバー：大きな設計変更や価格の変化がなければ替える | **SN65HVD230 → TJA1042T/3** に変更（回路図も修正済み） |
| 2. ブリッジ：分かれてもよいので分かりやすく | 中央パネルをやめ、**機能ごとの4グループ**に分けて、それぞれ使う回路の横に置いた |
| 3. XIAOを下端に戻す | 問題なし（そのまま） |

- **基板**：140×91mm（v2.3と同じ）
- **ファイル**：`pwrctrl_place.kicad_pcb`、`placement_v2.4.png`、`silk_preview_v2.4.png`、生成スクリプト `gen/place_v24.py`
- **回路図**：`pwrctrl.kicad_sch`／`pwrctrl.net`／`pwrctrl_sch.pdf`（ERC 0件）。変更前の生成スクリプトは `gen/main_sch_v2.0.py` に残した

## 1. CANトランシーバーの変更（SN65HVD230 → TJA1042T/3）

| 項目 | SN65HVD230 | TJA1042T/3 |
|---|---|---|
| CANH/CANLの耐圧（絶対最大定格） | −4〜16V | **−58〜+58V** |
| バスピンのESD | HBM ±16kV | IEC 61000-4-2 ±8kV、HBM ±8kV |
| 電源 | 3.3V | VCC 5V（4.5〜5.5V）＋ VIO 3.3V（論理レベル） |
| 8番ピン | RS（Lで高速） | STB（Lで通常動作） |
| パッケージ | SOIC-8 | SOIC-8（ピン配置もほぼ同じ） |
| 価格（LCSC、1個） | 約$0.31〜 | 約$0.55（C132227、在庫あり） |

- **耐圧の問題が解消**：PESD1CAN（約36〜50Vでクランプ）より、トランシーバーの耐圧（±58V）のほうが高くなった。24Vでのジャンプスタートやバスの短絡にも耐える
- **回路の変更点**
  - U6の3番ピンを＋3V3から**＋5V**へ
  - 5番ピン（未接続だった）を**VIO＝＋3V3**へ
  - C14（100nF）は＋5V用にした。VIO用に **C18（100nF）** を1個追加した
- **変えていないもの**
  - R60（10kでGNDへ）はSTBをLにするので、そのまま通常動作になる。R61（送信のプルアップ）、JP1、JP4／JP5もそのまま
- **ファームウェア**：変更不要（UARTやTWAIの扱いは同じ）
- **＋5Vの消費**：受信だけなら約5mA、送信時に最大70mAが増える

## 2. ブリッジ（はんだジャンパー）の配置と名前

| グループ | 場所 | ブリッジ（シルクの名前） |
|---|---|---|
| VEHICLE COMM（枠付き） | 車両ブロックとXIAOの間 | K_DRV（JP7）、K_TX（JP6）、CAN_TX（JP1）、VEH_TX：CAN｜K（JP4）、VEH_RX：CAN｜K（JP5） |
| GPS | GPSコネクタ（J16）の上 | GPS_PWR：3V3｜5V（JP8）、PPS>D10（JP9） |
| PC BUTTON | フォトカプラ（U3）の下 | D10>PC_BTN（JP2） |
| I2C | プルアップ抵抗R30/R31の横 | I2C_PU（JP3、文字は縦書き） |
| TEST | VEHICLE COMMの下 | ＋3V3（TP5）、GND（TP10） |

- **D10を3か所で共用していることを名前で示した**
  - GPS側の「PPS>D10」：PPSをD10へ入れる
  - PC側の「D10>PC_BTN」：D10でPCボタンを押す
  - AUXの4番ピンの表示：「SIG」を「D10」に変えた
- **3パッドのブリッジ**：両端に何につながるかを書いた（CAN／K、3V3／5V）
- **出荷時からつながっているもの**：I2C_PU と GPS_PWR の3V3側。どちらも基板上に銅のつなぎが見える
- **v2.3（中央にまとめた案）と比べると、配線が短くなった**

| 信号 | v2.3 | v2.4 |
|---|---|---|
| PWRB | 71mm | 6mm |
| GPS_PPS | 32mm | 11mm |
| GPS_VCC | 24mm | 15mm |
| I2C_PU | 32mm | 5mm |

## 3. J3と保護回路（v2.3と同じ配置）
- **線の順序**：J3 → U7（CANのESD保護）／TVS3（K-Line）→ ICの順で、保護素子の後ろにICがある。K-Lineにつながる部品（R14・F3）もTVS3より後ろ
- **J3から保護素子まで**：約10mm。ピン表示の文字を挟むため
- **GND**：U7とTVS3のGNDは5mm。表面のGNDでJ3のGNDピンへまとめる
- **配線のときの条件**
  - K-Lineは手で配線する
  - 保護素子のGNDには、ビアを2本以上打つ
  - J3から保護素子までの区域では、裏面に配線を通さない

## 4. 中央部分
- VEHICLE COMMの枠とTESTを、車両ブロックとXIAOの間に置いた
- XIAOの真上（x 52〜80、y 53〜63）は、**配線の通り道として空けてある**。ここを通る線は次のとおり
  - 車両側のジャンパーからXIAOのD8/D9（VEH_TX/RX）へ
  - XIAOから車両ブロックへの＋3V3・＋5V
  - D10（PC BUTTONへ）
  - HOLD（リレー保持回路へ）
  - ACC_IN
