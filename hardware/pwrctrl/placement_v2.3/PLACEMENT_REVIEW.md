## 1. J3（車両側コネクタ）と保護回路の検証

### 守るべき条件（距離だけで判断しない）
TIのESD対策レイアウト資料（SLVA680A）の要点は次のとおり。
1. 保護素子は、コネクタから入ってきた線が**最初に**通る部品にする。ICは保護素子の後ろに置く（線は保護素子のパッドを経由してからICへ。分岐の枝を作らない）
2. コネクタと保護素子の間は、まっすぐでビアなし。この区間の近くにほかの配線を通さない
3. 保護素子のGNDは、低インダクタンスでGNDプレーンにつなぐ（パッドの直近に複数のビア）
4. 戻り電流はコネクタのGNDピンへ短く帰す

### 確認結果
| 項目 | ユーザー配置 | v2.3 | 判定 |
|---|---|---|---|
| 線の順序（J3 → 保護素子 → IC） | ○ | ○。K-LineはTVS3 → C17 → U4（LIN）と順に通る。プルアップのR14と直接駆動のF3も、TVS3より後ろに置いた | ○ |
| J3から保護素子まで（保護されていない区間） | K 11.0／CAN 10.5mm | K 11.0／CAN 10.1mm | △ 下の説明を参照 |
| 保護素子からICまで | 8.0〜8.7mm | 6.9〜7.4mm | ○ |
| 保護されていない区間の線の形 | 斜めに上がる（K線とCAN線が近づく） | 3本ともJ3のピンからまっすぐ横に入る。間隔はピンと同じ2.5mm | ○ |
| ESD素子（U7）とTVS3のGNDパッドどうしの距離 | 7.9mm | 5.0mm（表面のGNDでまとめてJ3のGNDピンへつなぐ） | ○ |

**保護されていない区間（約10mm）について**：これは、ピン表示の文字（GND／CANL／CANH／KLINE）をJ3のすぐ横に置いたためにできた区間です。
- J3は基板の端にあるので、左側に文字を置く場所がありません
- この区間には文字以外を置かず、配線も通しません
- 裏面はGNDプレーンを切らずに残します。こうすると戻り電流は信号線の真下を通り、ループは小さくなります
- 文字をJ3から離せば約6mmまで縮められますが、ピン表示が分かりにくくなるので、今回は文字を優先しました

**配線のときの条件（この配置の前提）**
- K-Lineは「J3 → TVS3 → C17 → U4／R14／F3」の順に手で配線する。自動配線だとF3やR14がJ3のピンに直接つながり、保護前の枝ができるため
- U7とTVS3のGNDパッドには、それぞれビアを2本以上打つ
- J3のGNDピン、U7のGND、TVS3のGNDを表面のGNDでまとめる
- J3から保護素子までの区域では、裏面に配線を通さない

### 回路側で見つかった問題（配置では解決しない。要検討）
- **CANトランシーバー（SN65HVD230）のバスピンの絶対最大定格は −4〜16V**。一方、ESD保護（PESD1CAN）は24V系向けで、降伏電圧は最小26V、1Aで約36Vにクランプする
- そのため、**16〜26Vの直流の異常には保護が効かない**（例：24Vでのジャンプスタート、配線の短絡）。100Ωを通した過渡パルスなら±25Vまで耐えられる
- 12V車の通常の電圧（最大約14.5V）なら定格内だが、余裕は小さい
- 対策の候補は、バス故障保護（±40〜58V）付きのトランシーバーに替えること。ただし回路の変更になるので、今回は変えていない
- K-Line側は問題ない。TJA1021のLINピン（±40V）とSMAJ24Aの組み合わせで足りている

## 2. ピン表示（シルク）の確認と修正
ユーザーが書いた表示を残し、次の点を直した。全ポートについて、文字と実際のピンの信号を自動で照合し、一致を確認した。

| 場所 | 修正 |
|---|---|
| I2Cの列 | 「SDL」を「SCL」に直した（誤字）。改行が混ざっていたのも削除した |
| GPS | 「TX／RX」を「TXO／RXI」にした。TXO＝この基板から出る（D6）→ GPSのRXへ。RXI＝この基板に入る（D7）← GPSのTXから。基板側から見た名前か、GPS側から見た名前かで逆になる取り違えを防ぐため |
| PULSE A/B、AUX | 「VSW／VCC」を「12V／5V」にした。VSWは内部の名前なので分かりにくい。AUX（J17）にも同じ表示を付けた（J17は行の高さがJ8/J9と違うため） |
| PC BUTTON（J4） | 「＋／−」を付けた。PC817は極性があるため |
| 文字の大きさ | 0.8mm／線幅0.1mmを、1.0mm／0.15mmにした（JLCの最小値） |

## 3. 中央の空いた部分 → CONFIG／TESTパネル
- **空いていた理由**：上の電源ブロック（y 0〜50）と、下のXIAO・車両・コネクタ列（y 53〜）の間に、何も置かない帯ができていた
- **対策**：XIAOの真上（x 34〜80、y 45〜61）に、ブリッジ（はんだジャンパー）9個とテストポイント2個を集めたパネルを置いた
- 設定と測定をする場所が1か所にまとまり、XIAOや電源部品から離れていて、はんだごてが入れやすい
- パネルの下（y 61〜64）は、XIAOへ向かう配線の通り道として空けてある

## 4. ブリッジの名前と配置
| 列 | 名前（シルク） | 記号 | 内容 |
|---|---|---|---|
| VEHICLE COMM | K_DRV | JP7 | K-Lineの直接駆動を有効にする（5ボー初期化用） |
| | K_TX | JP6 | TJA1021の送信を有効にする |
| | CAN_TX | JP1 | CANの送信を有効にする（初期は受信のみ） |
| | VEH_TX：CAN｜K | JP4 | D8（送信）をCANかKにつなぐ。左のパッド＝CAN、右＝K |
| | VEH_RX：CAN｜K | JP5 | D9（受信）をCANかKにつなぐ |
| TEST | ＋3V3、GND | TP5・TP10 | テスター用 |
| I2C | I2C_PU＊ | JP3 | I2Cのプルアップ（出荷時はつながっている。切ると外れる） |
| D10：ONE ONLY | PC_BTN | JP2 | D10でPCの電源ボタンを押す |
| | PPS | JP9 | GPSのPPSをD10に入れる |
| GPS | GPS_PWR：3V3＊｜5V | JP8 | GPSの電源を3.3V（出荷時）か5Vにする |

- **D10の共用**：D10はAUX（J17）にも直接つながっているので、「D10：ONE ONLY」というまとまりにして、使うのは1つだけだと分かるようにした
- **初期状態**：＊の付いたものは、出荷時にブリッジ済み
- **かかる手間**：ジャンパーを中央に集めたので、関係する線は合計で約300mm長くなる（どれも低速の信号か、小さな電流）。各ジャンパーを使う回路の横に置く案もあるが、その場合はブリッジが4か所に散らばる

## 5. そのほかの変更
- **XIAOを下端に戻した**：ユーザー配置では2.5mm上がっていて、USB-Cが基板の端から4.5mm内側になっていた。ケーブルの抜き差しとケースの穴のため、端に戻した
- **C13（3V3）とC9（5V）**：XIAOのピンの横に戻した（12.5mm→3.0mm）
- **I2Cの列**：3.5mm左へ移動した（140mm幅に収めるため）。J5は0.5mm左へ
- **U3（PC BUTTON）**：1mm左へ移動した（＋／−の表示を入れるため）
- **F4（PTC）**：向きを変えた。VSW_EXTが上に出て、上端に沿ってセンサー用電源へ行ける
- **K直接駆動の論理部（Q8・R20〜R22・R73）**：CONFIGパネルの左下に置いた
