# メイン基板（PWR-CTRL v2.0）レイアウト・配線記録

- 2層、1.6mm、外層2oz、**165×91mm**（2DINケースの内側に収まる大きさ）、M3取付穴5個
- ツール：KiCad 9.0.9（kicad-cli／pcbnew）＋ Freerouting 2.4.1。7Aの経路は手で配線
- 製造データ：`gen/export_main.sh`（ガーバー・ドリル・BOM・CPL・画像）
- 再生成手順：`gen/flow.sh`（配置 → 7A経路＋直交自動配線 → 角の45°面取り → GNDベタ（島を残す）→ スティッチビア → 島の除去 → サーマル修正 → シルク → 検査）

## v2.0の変更点（v1.8から）
- 拡張ハブの機能をメイン基板に統合した。I2C・GPS・パルス・AUXのポートをすべて基板上のJST XHにした
- Qwiic（JST SH、SM04B）を廃止し、JST XHに統一した
- センサー用の電源（5VS：XL7015、3V3S：AMS1117）を追加した。マイコンの電源とは分けている
- GPIO（D2・D3・D6・D7・D10）に100Ωの保護抵抗を入れた（XIAO側→ポート・J5側）
- I2Cのプルアップを4.7kから2.2kにした（400kHz向け。プルアップはマスター近くに1組だけ）
- J5（2×10）は残した（デバッグ・将来用）。13番ピンは5V_EXTから5VSに変えた。F5（0.25A PTC）は削除した
- パルス入力の変換回路は載せていない（外付けのPULSE-INアダプターをPULSE-A／Bにつなぐ）

## コネクタの配置（種類ごとにまとめた）
| 場所 | コネクタ |
|---|---|
| 左端：電源・車両 | J1 電源入力（+B/ACC/GND）、J2 DFR0946へのVSW出力、J3 車両診断（K/CANH/CANL/GND） |
| 右端：I2C（センサー） | 上からI2C1〜I2C4（3.3V）、I2C5（5V） |
| 下端：信号ポート | 左からPC電源ボタン（J4）、AUX（D10）、PULSE-B（D3）、PULSE-A（D2）、GPS、I2C6（5V） |
| 中央 | J5（2×10ヘッダー）、XIAO（USB-Cは下端向き） |

- 右下の角にI2C5とI2C6（どちらも5V）が集まるようにした
- ポートのシルクは機能名（例：I2C1 3V3、PULSE-A D2）で表示し、J番号は表示しない

## 配線の方針（Webで調べた一般的な鉄則と、その適用）
| 鉄則 | 出典 | この基板での適用 |
|---|---|---|
| 直角の角を作らず、45°で曲げる | Electronic Specifier「PCB routing guidelines: top 10 practices」 | 自動配線は直交（表＝横、裏＝縦）で行い、その後 `gen/chamfer.py` で90°の角をすべて45°に面取りした。DRCで問題が出た面取りだけ元に戻す（234か所を面取り） |
| GNDプレーンを切らない（帰り電流の通り道） | 同上、PCBSync「I2C Bus PCB Layout」 | 斜めの長い配線をやめて直交配線にし、裏面の長い横断をなくした。配線で囲まれて孤立したGNDの島は、消す前にスティッチビアで裏面とつなぐ（`pour.py`→`stitch.py`→`gnd_reinforce.py`）。GNDのつなぎのビアは398個（下の「GNDプレーンの連続性」を参照） |
| 降圧回路：入力コンデンサをVINとGNDの直近に置き、ホットループを小さくする。SWノードは短く、面積は小さく。FB抵抗はFBピンの近くに置き、SWから離す | TI LMR33610データシート「Layout Guidelines」（XL7015のデータシートにはレイアウトの章がないため、一般的な降圧回路の指針を使用） | U1・U8を同じ形の小さなまとまりに配置し直した（下の「DC-DC」参照） |
| VIN・VOUT・GNDは太く直接 | 同上 | ネットクラス：7A経路3.0mm（手配線）、1A系0.8mm（VSW_EXT、5VS、SW6、VBAT_IN、ACC_IN、V5REGなど）、0.5A系0.6mm（VSW分岐、+5V、3V3S、GPS_VCC）、信号0.25mm。部品間の最小間隔は0.25mm（ポート信号のSIG_PORTクラスだけ0.21mm） |
| I2Cのプルアップは1組だけ、マスターの近くに。400kHzなら2.2k程度。SDAとSCLは並べて、切れ目のないGNDの上を通し、スイッチング電源から離す | PCBSync「I2C Bus PCB Layout」 | R30/R31（2.2k）をXIAOの近くに置いた。SDA/SCLは並走させ、右端のI2Cポートまで表面の横方向に通した |

## GNDプレーンの連続性と電流の帰り道（v2.0で検証・補強）
`gen/gnd_audit.py` で確認し、`gen/gnd_reinforce.py` で補強した。結果は `gnd_audit.txt`。ビアの数を減らすことより、GNDのつながりと帰り道を優先した。

### 1. 孤立した銅箔
- 表面GND：主面12,349mm²（基板の82%）。ほかに6つの小さな領域があり、すべてビアで裏面とつながっている
- 裏面GND：主面11,462mm²。ほかに12の小さな領域があり、どれも浮いていない（つながっていない銅箔はKiCadの「孤立島の除去」で削除済み）
- 裏面の小さな領域の正体：裏面の配線に挟まれた細長い部分や、コネクタのピンの間の部分（J5、I2Cポート、J16の付近）

### 2. GNDの島のつながり方
- 消す前の島にビアを打って表面とつなぎ、それでも浮いている島だけを消す手順にした（pour.py → stitch.py → gnd_reinforce.py）
- 裏面の233mm²と185mm²の領域は、それぞれ14本・5本のビアで表面のGNDとつながっている
- ビアが1本だけの領域：表面3つ（40.7mm²：J5の左、12.2mm²、3.7mm²）、裏面3つ（29.1mm²：I2C5の横、15.7mm²：GPSコネクタの横、1.0mm²）。部品とパッドで場所がなく2本目を打てない。どれも41mm²以下で、電流の通り道ではない

### 3. 大電流の経路とDC-DCの帰り道
| 経路 | 確認結果 |
|---|---|
| 7A（J1→K1→TVS1→J2） | 行きは裏面3.0mm、帰りは表面3.0mmの専用配線（J1-3/4→J2-2）を行きの近くに並べ、ループ面積を小さくした。J1-3/4とJ2-2のGNDピンはベタに直結（サーマルなし） |
| U1（マイコン用5V） | GNDパッド8個がすべて表面GNDの主面にある。周囲8mm以内にGNDビア7本 |
| U8（センサー用5VS） | 同じく8個が主面にある。GNDビア10本 |
| U9（3V3S LDO） | 3個が主面にある。GNDビア12本 |

- 裏面の長い配線（15mm以上）は、両側に5mm間隔でGNDビアを並べた（フェンス）。帰り電流は表面に移って、配線の切れ目をまたげる
- 近くのGNDビアが少ないもの：IO_D3（2本）、IO_D2・ACC_SENSE（4本）。どれもXIAOの横の部品が密集した所で、低速の信号

### DC-DC（U1・U8）の配置し直し（v2.0、外部レビュー対応）
最初の配置はU1の入力コンデンサがVINから23mm、SWの配線が34mmあり、ホットループが大きかった。U1とU8を同じ形の小さなまとまりに配置し直した。

| 項目 | 変更前（U1） | 変更後（U1／U8） |
|---|---|---|
| セラミック入力コンデンサ（C5／C41）～VINピン | 23mm | 4.6mm |
| ダイオード（D11／D12）のカソード～SWピン | — | 3.8mm |
| インダクタのSWパッド～SWピン | — | 8.1mm |
| SWノードの配線 | 34mm | 8.5mm、6.8mm² |
| ホットループ（Cin→VIN→SW→D→Cin）の面積 | 約163mm² | 約3mm² |
| FB分圧抵抗～FBピン | — | 5.2mm／4.7mm（SWから離して配置） |
| 大容量の電解コンデンサ～VIN | — | C4：33.5mm／C40：12.3mm |

- XL7015データシート（Rev1.7）を確認した。レイアウトの章はない。ピン5はEN（Lで動作、開放でもL）。この基板ではGNDにつないでいるので常に動作する（意図どおり）。金属タブはGND
- 部品の値はデータシートの応用回路と同じ考え方（100µH、Vref 1.25V、33nFのフィードフォワード、150kHz）
- C4（470µF）はVINから33.5mmある。高周波の電流はC5（1µF）が受け持つので大きな問題ではないが、改良するなら近づける

### 電源配線の幅と電流（IPC-2221、外層2oz、温度上昇10℃）
| 配線 | 流れる電流 | 最も細い所 | 許容電流 |
|---|---|---|---|
| 7A経路（VBAT_IN／VSW／GND） | 7A | 3.0mm（手配線） | 7A以上 |
| VSWの分岐（F4・保持回路など） | 1.1A以下 | 0.6mm | 2.7A |
| ACC_IN、V5REG、SW5、SW6、+5VS | 0.8A以下 | 0.8mm | 3.4A |
| +5V、VSW_EXT、VIN5、GPS_VCC | 1.1A以下 | 0.6mm | 2.7A |
| +3V3S | 0.4A | 0.45mm | 2.2A |
| +3V3 | 0.25A | 0.3mm | 1.6A |

### 4. ビアの内訳（合計542個、すべて0.85/0.3mm）

## 外部レビュー（画像による確認）への回答
- 層数：2層（1.6mm、外層2oz）
- layer_top.pngの赤色は表面の銅箔（GNDベタ）。白い線は銅箔のすき間。基板の色はrender_3d_top.pngで確認できる
- layer_top.pngは表面だけ。裏面はlayer_bottom.png（左右反転して表示）
- 中央の長い並走（J5まわり）：信号はすべて低速（GPIO、UART、CAN 500k、I2C 400k）。並走の間隔は0.46～1.3mm。表面の長い配線（15mm以上、21本）の下に裏面GNDがある割合は平均79%、最小55%（+3V3）
- U2（XIAO）まわり：最小間隔0.252mm。車両通信まわり：0.250mm。0.21mmなのはJ5まわりのポート信号だけ（JLCの標準は0.1mm以上）
- 検証ツール：`gen/review_check.py`（結果は `review_check.txt`）、`gen/gnd_audit.py`（`gnd_audit.txt`）

## 検査結果
- DRC（JLCルールの .kicad_dru を適用）：違反0、未接続0
- 独自検査：部品外形の重なり0、基板外へのはみ出し0、シルク線幅0.15mm以上、文字高1.0mm以上
- シルクとパッド・穴の距離：表0.22mm以上、裏0.35mm以上（JLCの基準0.18mm以上）
- ERC：0件
- ビア：合計542個（うちGNDのつなぎ398個）、0.85/0.3mm

## 気になる点・今後の確認
- 自動配線なので、人が引くより曲がりの数が多いところがある。必要ならKiCadで手直しする
- XL7015が2個になった（マイコン用とセンサー用）。どちらも同じ回路・同じ部品・同じ配置
- 残りの小さな改善点：C4をU1に近づける、J5まわりのポート信号の間隔0.21mm、ビア1本だけのGND小領域（6か所）
- 基板が大きくなったので、ケースの寸法と取付穴（5個）の位置を確認する
