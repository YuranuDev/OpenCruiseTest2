## 1. ユーザーのコネクタ配置の確認

| コネクタ | ユーザーの配置 | v2.2での扱い |
|---|---|---|
| J1・J2（電源） | 左端のまま | そのまま |
| J3（車両診断） | 車両ブロックの上（基板の内側、横向き） | そのまま。保護部品と送受信ICをJ3の真下に置き直した |
| I2C1〜I2C6（J6・J7・J12〜J15） | 下側に横一列。すべて縦向き（90°） | 並びはそのまま。行全体を左へ8mm、上へ1mm動かした（基板を縮めるためと、右下の取付穴を入れるため） |
| AUX・GPS・PULSE-A/B・PC BTN（J17・J16・J8・J9・J4） | I2Cの上にもう一列 | 並びはそのまま。J17以外を左へ8mm動かした |
| J5（2×10） | XIAOの右、下端の近く | そのまま |
| JP8・JP9（GPSの電源・PPS） | J16の左 | そのまま（列と一緒に移動） |

**よい点**
- I2Cの6個が1列に並び、4本の線（GND・電源・SDA・SCL）を各コネクタのピンに通すだけでつながる
- I2Cの配線長は、v2.1案の約165mmから約66mmになる。J5のSDA/SCLピンを経由して右へ出せばよい
- 同じ種類のコネクタがまとまり、向きも揃っていて分かりやすい

**気になる点（変更はしていない）**
1. **コネクタどうしの隙間が狭い**：I2Cの列は7.4mm間隔で、ハウジングの隙間は約1.6mm。指でプラグをつまんで抜くのは難しく、抜くときはピンセットなどが必要。指で抜きたい場合は、間隔を9mm程度（隙間3mm以上）にする必要がある。そうすると基板の幅が約+10mm増える
2. **ケーブルが基板の上を通る**：コネクタが基板の内側にあるため、ケーブルは上へ出してからケースの外へ回す。ケースの高さ（基板から上蓋まで）に、XH（高さ7mm）＋ケーブルの曲げの余裕があるか確認が必要
3. **J3（車両側）が基板の内側にある**：車からのノイズやサージが基板の中ほどに入ってくる。対策として、保護部品（TVS3・U7）をJ3から6mm以内に置いた。電気的には問題ない

どれも「無理」ではないので、配置はこの形を保った。

## 3. 制約とトレードオフ
- **さらに小さくするのは難しい**。高さは、上の電源ブロック（y 0〜50）、XIAO（下端のUSB-C）、I2Cの列で決まる。幅は、左の電源・車両ブロック、XIAO、コネクタ2列で決まる
- **K-Lineの送信信号（KL_TXS）は長くなった**（15→35mm）。K-Lineのバス側の部品をJ3の近くに集めたため。KL_TXSは3.3Vの低速信号なので問題ない
- **IO_D10（PC電源ボタン）は約69mm**。XIAOからJ4までの距離のため
- **I2C列を1mm上げた**。右下の取付穴（129,87）を入れるため

## 4. 配線上の懸念
- **I2C**：XIAO横のR30/R31 → J5の5・6番ピン → I2C列の3・4番ピンへ横に通す。SDAとSCLは並べる
- **VSW_EXT**：F4から上端に沿ってx 91まで行き、上辺の穴（95.5,4）の手前で下りてC40へ。下側の列（J17・J8・J9）へは、別にセンサー用電源の左側を通して下ろす
- **2列目のポートの電源**（1番：12V、2番：5V）：J17・J8・J9の1・2番ピンを横につなぐ
- **J4とU3の間の2本**：ピン順の関係で1回交差する（ビア1つ）
