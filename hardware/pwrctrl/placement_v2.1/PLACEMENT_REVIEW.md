## 1. 配置計画（機能ブロックと流れ）

### 電源の流れ（左上から右下へ）
J1（+B/ACC）→ K1リレー → VSW → J2（PC電源、7A）と TVS1・C1～C3
- VSW から上端のD7を通って VIN5 → U1（マイコン用5V）→ D8 → XIAOの5Vピン（下中央）
- VSW から上端のF4を通って VSW_EXT → U8（センサー用5VS）→ U9（3V3S）→ 右端のI2Cポート・下端のポート・J5

### 信号の流れ
- 車両：J3（左端）→ 保護（U7・TVS3）→ 送受信IC（U6・U4）→ プルアップ・ジャンパー → JP4/JP5 → XIAOの左側ピン
- XIAOの右側ピン → 直列抵抗・I2Cプルアップ → J5／下端のポート／右端のI2Cポート

### ブロックごとの配置
| ブロック | 場所 | 配置意図 |
|---|---|---|
| 1 電源入力・7A | 左上 | 7Aのループ（J1→K1→TVS1→J2→GNDでJ1へ）を左上の角にまとめた。ACC_INの保護（TVS2）はJ1のACCピンとGNDピンの真上に置いた |
| 3 リレー保持 | K1のコイル端の右 | フライバックダイオードD5をコイル端子A1/A2の間に置いた。OR用のD1/D2、ローサイドのQ1もコイル端子の隣に置いた。HOLD_Nの部品（R1・R3・C11・R2・ZD1）は横一列に並べ、上側をHOLD_Nの共通線にした |
| 2 マイコン用5V（U1） | 上の中央 | 下の「降圧回路の形」を参照。入力（D7/D9→C4）を上に、出力（L1→C7/C6→D8）を下（XIAOの方向）に置いた |
| 7 センサー用電源（U8・U9） | 右の中央 | 負荷（右端のI2Cポート、下端のポート、J5）の近くに移した。+5VSと+3V3Sの配線が短くなる（+5VS 199→157mm、+3V3S 136→102mm）。U1から離れたので、スイッチング電源同士の干渉も減る |
| 4 XIAOとピンの部品 | 下の中央 | XIAOの右側のピン列に合わせて、ピン1本に部品1つを2.54mm間隔で縦に並べた（直列抵抗R80～R84、I2CプルアップR30/R31、ACC電圧のC12/R6/ZD2/R5）。左側にはC13（3V3）とC9（5V）をピンの横に置いた |
| 5 車両通信 | 左下 | 左から右へ：J3 → 保護 → 送受信IC → プルアップ・ジャンパー → JP4/JP5。CANを上段、K-Lineを下段に置いた |
| 6 J5・PC電源ボタン | XIAOの右 | J5のピン順（下から ACC/HOLD、D2/D3、SDA/SCL、D6/D7…）は、XIAO横の部品列の並び順と同じになる。配線が交差せずに扇形に集まる。U3はJ4の真上に置いた |
| 8 ポート | 右端・下端 | 種類ごとの並びは同じ。下端だけ、AUX（J17）とPC電源ボタン（J4）を入れ替えた（理由は3章） |

### 降圧回路の形（U1・U8で同じ）
XL7015はVINとSWが隣り合うピン（1番と2番）なので、次の形にした。
- C5（セラミック）をVINピンの左、D11をSWピンの左に置いた。C5のGNDとD11のアノードは3.7mmで隣り合う
- C4（電解）はICの真上に置いた。＋はVINピンの上、−はGNDタブの上
- L1はD11の下に置いた（SW側のパッドが上）
- FB分圧（R51・R50・C8）はICの下、ピン列の反対側に置いた。FBの配線はICの本体の下を通し、SWノードやL1から離す

## 2. 重要部品の配置理由
- **C4・C40（入力の電解コンデンサ）**：XL7015は150kHzで動作する。1µFのセラミック（C5・C41）は150kHzでは約1Ωで、リップル電流の大部分は電解コンデンサを流れる。そのため電解コンデンサもホットループの一部とみなし、ICの直近に置いた（データシートの応用回路も、入力は33µFの電解だけ）
- **C12（ACC電圧のフィルター）**：ADCピン（D0）から3.8mm。分圧した後の高インピーダンスの線は約5mmだけ。長いのは12VのACC_IN（雑音に強い）の側にした
- **TVS2・U7・TVS3**：保護素子をコネクタの入口（6mm以内）に移した
- **R80～R84（直列抵抗）**：XIAOのピンの直近に置いた。J5と複数のポートに分かれる前に1か所で保護する
- **F4（VSW_EXTのPTC）**：VSWを分ける所（D7の隣）に移した。VSW_EXTの長い配線（U8、J5、下端のポートへ）はすべてPTCの後ろになる
- **D5（フライバック）**：リレーのコイル端子の間に置いた（14mm→約4mm）
- **D8（5Vの逆流防止）**：U1の出力側に置いた。カソード側をXIAOの方向（下）に向けた
- **U3（フォトカプラ）**：J4の真上に置いた

## 3. 制約とトレードオフ
- **外形と端のコネクタは変えていない**。そのため右上（x 93～156、y 0～35）に部品のない領域が残る。この領域は配線と連続したGNDプレーンに使い、2つのスイッチング電源の間隔にもなる
- **J4（PC電源ボタン）とJ17（AUX）を入れ替えた**。XIAOの右下にACC電圧の部品を置く場所を作るため。種類ごとのまとまり（下端＝信号ポート）は変わらない。**ケースの穴やケーブルの割り当てに影響する場合はお知らせください**
- **センサー用電源を右上から右の中央へ移した**。+5VS・+3V3S・VSW_EXTが短くなる代わりに、I2Cの配線（XIAO→右端）はブロックの下か右を通す必要がある。SWノードとL2はブロックの左側（I2Cの反対側）に向けた
- **直列抵抗をXIAOの近くに置いた**。IO_D*は短くなった（約45mm→4mm）が、外へ出るP_D*は長くなった（例：P_D7 47→69mm）
- **F4をVSWを分ける所に移した**。保護の範囲は広がったが、VSW_EXTの配線は少し長くなった（145→172mm）
- **J5は基板の内側のまま**。フラットケーブル用のボックスヘッダーで、ケーブルは上に出す。外周には空きがない
- 0603の向き：XIAOの横、HOLD_Nの列、LEDとその抵抗は揃えた。車両通信のブロックは、ピンに近づけることを優先したので、縦と横が混ざっている

## 4. 配線上の懸念
- **I2C（SDA/SCL）**：XIAO横から右端と下端のポートまで約165mmあり、配置では短くできない。SDAとSCLは並べて、GNDの切れ目の上を通らないようにする。センサー用電源のL2・D12（左側）には近づけない
- **HOLD・ACC_IN**：上端（リレー・J1）とXIAO（下）の間に縦長の配線が必要。表面の空いた所を通し、裏面のGNDを切らないようにする
- **VSW_EXT**：F4（上端）からU8・J5・下端のポートまでの幹線。表面のリレーとU1の間の溝（x 66～70）を下りる想定
- **IO_D7/IO_D10/VEH_TX/VEH_RX**：XIAOの下（左右のピン列の間）を横切る。ソケットの下なので部品は置かない
- **J4とU3の間の2本**：ピン順の関係で1回交差する（ビア1つ）
- **U1/U8のFB**：ピン4から本体の下（ピン列とタブの間）を通して分圧抵抗へつなぐ。SWノード側には出さない

## 5. 未解決の問題
- **入力のリップル電流**：C4（470µF/50V）とC40（100µF/50V）のリップル電流の定格が、XL7015の入力リップル（最大約0.4A rms）に足りるかを部品の仕様で確認したい（回路の変更になるので、今回は触っていない）
- **熱**：U1・U8（TO-252）の上に電解コンデンサがある（約5mm）。U9（SOT-223、最大約0.8W）の左隣にC42がある。電解コンデンサの寿命は温度に左右されるので、配線のときにタブの周りの銅箔を広く取る
- **J4とJ17の入れ替え**の可否（3章）
- **シルク**：部品番号の位置は配線の後のシルク工程で直す（現時点で重なり11件）

## 7. 訂正
前回の報告で、DC-DCのホットループの面積を「約3mm²」としていた。これは部品のパッドを結んだ多角形が線に近い形になったための計算上の値で、実際の大きさを表していなかった。今回からは、経路長（C5→VIN→SW→D→C5 GND）で比べる。v2.0は26.3mm、v2.1案は18.3mm。
