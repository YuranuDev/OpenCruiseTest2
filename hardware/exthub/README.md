# 拡張ハブ EXT-HUB v1.0 ＋ 拡張の割り当て表

> **v2.0でメイン基板に統合済み。この基板は製造しない。** ピンの割り当て・I2Cアドレス予約表（5章）は引き続き有効。ポートの配置はメイン基板（power-board-design.md 8章、pwrctrl/LAYOUT.md）を参照。メイン基板ではQwiicを廃止し、I2C1〜4もJST XHになった。プルアップはメイン基板の2.2k（1組）だけ

関連：claude/power-board-design.md（v1.8）、claude/firmware-config-spec.md（v1.7）、claude/pulse-input-adapter.md
KiCadデータ：OpenCruiseTest2/hardware/exthub（生成スクリプト：gen/exthub_sch.py、place_exthub.py、route_exthub.py、silk_exthub.py、flow_exthub.sh）

## 1. 考え方
- XIAOの空きピンは少ないので、**「どのピンを何に使うか」を先に決め、用途ごとに専用のコネクタを常設する**
- センサー類は基本的に**I2C**でつなぐ（2本の線に何台でもつなげる）。I2Cのコネクタを6個用意し、どこに挿しても同じバスにつながる
- メイン基板は変更しない。メイン基板のJ5（2×10）からフラットケーブルで拡張ハブにつなぐ
- 拡張ハブは**自前の5V・3.3V電源**を持つ（メイン基板のVSW＝12Vから作る）。センサーを増やしても、マイコンの電源に負担をかけない

## 2. XIAOのピン割り当て（確定）
| ピン | 用途 | つなぐ場所 | 変更 |
|---|---|---|---|
| D0 | ACC検知・電圧計 | メイン基板内 | 不可 |
| D1 | HOLD（リレー保持） | メイン基板内 | 不可（拡張ハブには出さない） |
| D2 | パルス入力A（車速） | ハブ PULSE-A／メイン J8 | 他の用途も可 |
| D3 | パルス入力B（回転数） | ハブ PULSE-B／メイン J9 | 他の用途も可 |
| D4／D5 | I2C（SDA／SCL） | ハブ I2C1〜6／メイン J6・J7 | 不可（センサー用のバス） |
| D6／D7 | UART（GPS） | ハブ GPS | GPSを使わなければ2本目のI2Cなどに使える |
| D8／D9 | 車両通信（CAN／K-Line） | メイン基板内 | 不可 |
| D10 | 予備（PPS・1-Wire・割り込み） | ハブ AUX（またはGPSのPPS、JP3） | 用途を1つ選ぶ |

## 3. 拡張ハブのコネクタ
| 名前 | 記号 | コネクタ | ピン（1→） | 用途 |
|---|---|---|---|---|
| メイン基板から | J1 | 2×10 ボックスヘッダー | メインJ5と同じ番号 | フラットケーブル（赤い線が1番） |
| I2C1〜I2C4 | J2〜J5 | Qwiic（JST SH 4P） | GND／3V3／SDA／SCL | 3.3Vのセンサー基板（Qwiic・STEMMA QT）をケーブル1本で |
| I2C5・I2C6 | J6・J7 | JST XH 4P | GND／5V／SDA／SCL | 5V電源が必要なモジュール、少し長い配線。信号は3.3V |
| GPS | J8 | JST XH 5P | GND／VCC／RX(D6)／TX(D7)／PPS | GPSモジュール。VCCはJP2で3.3V（初期）か5V |
| PULSE-A | J9 | JST XH 4P | 12V／5V／GND／D2 | PULSE-INアダプター（車速） |
| PULSE-B | J10 | JST XH 4P | 12V／5V／GND／D3 | PULSE-INアダプター（回転数） |
| AUX | J11 | JST XH 4P | 12V／5V／GND／D10 | 1-Wire温度センサー、割り込み入力、スイッチなど |

- PULSE-A／B・AUXはメイン基板のJ8/J9と同じピン順。PULSE-INアダプターはどちらにもストレートのケーブルでつなげる（ただし同じピンを2か所で使わない）
- GPIO（D2・D3・D6・D7・D10）には100Ωの直列抵抗を入れ、配線ミスからXIAOのピンを守る
- ジャンパー：JP1（I2Cプルアップ2.7k、初期は接続。切ると外れる）、JP2（GPS電源 1-2:3.3V／2-3:5V、初期は3.3V）、JP3（GPSのPPSをD10へ。初期は開放）

## 4. 電源
| 電源 | 作り方 | 容量（合計） | 使う場所 |
|---|---|---|---|
| 12V | メイン基板のVSW_EXT（F4 1.1A） | 拡張ハブの5V電源分を引いて約0.7A | PULSE／AUXの1番ピン（12Vセンサー用） |
| 5V | XL7015（メイン基板と同じ回路、5.3V） | 約0.7A | I2C5・6、PULSE／AUXの2番、GPS（JP2） |
| 3.3V | AMS1117-3.3（5Vから） | 約0.4A（発熱の上限） | I2C1〜4、GPS（初期）、I2Cプルアップ |

- 拡張ハブはACC ON（リレーON）の間だけ動く。エンジンを切れば電源は切れる（暗電流ゼロのまま）
- メイン基板のJ5の3V3（12番）と5V_EXT（13番）は使わない（電源をぶつけないため）

## 5. I2Cアドレスの割り当て（ぶつからないように予約）
| アドレス | 用途（予定） | 部品の例 |
|---|---|---|
| 0x20〜0x27 | I/Oエキスパンダー（スイッチ・LED・リレー） | PCA9555／MCP23017 |
| 0x3C | 小型表示器 | SSD1306 |
| 0x40〜0x45 | 電流・電力 | INA226／INA219 |
| 0x48〜0x4B | アナログ入力（油温・油圧・ブースト・燃料など） | ADS1115（4台で16ch） |
| 0x68／0x69 | 加速度・ジャイロ | ICM-42688／MPU-6050 |
| 0x70 | I2C切り替え（同じアドレスの機器が必要になったとき） | TCA9548A |
| 0x76／0x77 | 温度・湿度・気圧 | BME280 |
| 0x42 | GPSのI2C（使わない。GPSはUARTでつなぐ） | u-blox |

- 新しい機器を足すときはこの表に追記してから買う
- I2Cは400kHzで使う。プルアップは、ハブの2.7kとメイン基板の4.7k（JP3）が並列になり約1.7k（400kHzに適した値）
- 配線はハブから各センサーまで1m以内を目安にする。エンジンルームなど遠い場所は、PCA9615（差動I2C）や別のマイコン＋CANを検討する
