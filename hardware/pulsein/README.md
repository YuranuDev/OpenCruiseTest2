# パルス入力アダプター PULSE-IN v1.0

関連：claude/power-board-design.md（v1.8）、claude/firmware-config-spec.md（v1.6）、claude/spice-verification.md（tb7）
KiCadデータ：OpenCruiseTest2/hardware/pulsein（生成スクリプト：gen/pulsein_sch.py、place_pulsein.py、route_pulsein.py、silk_pulsein.py、flow_pulsein.sh）

## 目的
車速パルス・タコ信号・外付けセンサーのパルスを、XIAO ESP32S3で読める3.3Vの信号に変換する。メイン基板は変更せず、J8／J9（JST-XH 4P）に小基板をつなぐ方式にした。

- 1枚で1チャンネル。J8につなげばD2、J9につなげばD3に入る（2チャンネルまで）
- 3チャンネル目以降は、J5（D6・D7・D10と5V・12V・GND）からケーブルで分岐すればつなげる。パルスの読み取りにアナログ入力は不要なので、D6・D7も使える

## 仕様
| 項目 | 値 |
|---|---|
| 入力 | 0〜16Vの方形波（プッシュプル）、またはオープンコレクタ（JP1でプルアップ） |
| しきい値 | 立ち上がり約1.8V／立ち下がり約1.0V（JP2を閉じると約5.8V／3.2V） |
| 周波数 | 〜約10kHz（入力のRCフィルタ τ=22µs） |
| 耐圧 | 22kの直列抵抗と4.7Vツェナーで保護。40Vのスパイクでも74LVC1G17の入力は4.7V前後（SPICE tb7） |
| 出力 | 3.3Vロジック（74LVC1G17のプッシュプル、100Ω直列） |
| 表示 | パルスに合わせてLEDが点滅する（配線確認用） |
| センサー用電源 | J2から5V（メインのF5 0.25A）と12V（VSW、メインのF4 1.1A）を出す |
| 外形 | 34×28mm、2層、M3穴1個 |

## 回路
- J2（入力、XH 4P）：1 SIG_IN／2 GND／3 +5V／4 +12V
- JP1（3端子ソルダージャンパー）：1-2で5Vプルアップ、2-3で12Vプルアップ（R1 4.7k）。初期は開放
- R2 22k → SIG_A。C1 1nF、DZ1 BZT52C4V7でGNDへ
- R3 10k＋JP2：閉じるとしきい値が上がる（ノイズの多い12V信号向け）。**5V／3.3Vの信号では閉じない**（入力が届かず、出力が出なくなる。SPICEで確認済み）
- U1 74LVC1G17（3.3V動作、シュミット）→ R4 100Ω → J1-4
- U2 XC6206P332（5V→3.3V）、C2・C3 1µF、C4 100nF
- R5 1k＋D1 LED：パルスの表示
- J1（メイン基板へ、XH 4P）：1 +12V（VSW_EXT）／2 +5V（5V_EXT）／3 GND／4 OUT。**メイン基板のJ8/J9と同じ並びなので、ストレートのXH 4Pケーブルでつなぐ**

## 信号ごとのジャンパー設定（目安）
| 信号 | JP1 | JP2 | 備考 |
|---|---|---|---|
| 車速パルス（12V方形波） | 開放 | 開放（ノイズが多ければ閉じる） | 実車で波形を確認する |
| 車速パルス（オープンコレクタ） | 1-2（5V）または2-3（12V） | 2-3のときだけ閉じてよい | テスターで、つないでいないときの電圧を見ると判別できる |
| タコ信号（12V方形波） | 開放 | 閉じる | |
| 外付けセンサー（5V／3.3V出力） | 開放 | 開放 | センサー電源はJ2の5Vから取れる |
| 外付けセンサー（オープンコレクタ） | 1-2（5V） | 開放 | |

## 製造（JLCPCB）
- jlc/pulsein_gerber_JLC.zip、jlc/pulsein_BOM_JLC.csv（12品目14点）、jlc/pulsein_CPL_JLC.csv
- J1・J2（JST XH B4B-XH-A）は、メイン基板と同じくAliExpressで買って手はんだする（BOMとCPLから除外）
- U1のLCSC番号はメイン基板のU5と同じ（C151394）。DZ1 BZT52C4V7（C173408）だけが拡張部品
- 検査：ERC 0件、DRC 違反0・未接続0、シルクとパッドの距離0.22mm以上（JLCの基準0.18mm以上）

## 実車での確認事項
- Keiの車速パルスとタコ信号の取り出し位置、波形（電圧・プッシュプルかオープンコレクタか）
- 車速パルスの1kmあたりのパルス数（日本車は2548パルス/kmが多い。GPSで合わせる）
- タコ信号の1回転あたりのパルス数（3気筒は1.5パルス/回転が多いが、車種で異なる）
